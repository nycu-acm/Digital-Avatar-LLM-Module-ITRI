Technology introduction
5G collaborative network edge computing technology.
5G Synergic Edge Computing (SynerEdge) provides cloud computing capabilities and application services management at the edge of the 5G mobile network and at the locations adjacent to the base station.With 3GPP R16 UPF/AF and ETSI MEC architecture specifications, it can transfer application services running on Cloud on the traditional network architecture to the user's nearest 5G SynerEdge collaborative network edge computing platform to run on the following advantages:
1. Since the application service is close to users, the service delay time can be effectively reduced.
2. At the same time, data is calculated at the edge of the mobile network, which can effectively reduce the data load transmitted through the core network.
3. The OAM network management platform deploys the edge computing platform required for each field with one click.
4. Supports heterogeneous network access dedicated network technology, which can support 5G RAN and Wi-Fi access technology.
The system architecture of 5G SynerEdge supports running on Commodity Hardware; the ETSI MEC APP Platform Services developed by ITRI can provide APP management including: listing, removing, life cycle and Traffic Rules... etc. The APP can be built and run on a hybrid NFV platform that includes Hypervisor-base (VM) and Container-base.
