Technology introduction
5G system hierarchical emulator - WiSE.
In the stage of 4G/5G mobile communication technology development and standard formulation, in order to quickly evaluate the performance gains of various technologies, companies participating in standard formulation will use system-level simulation platforms (SLS) to conduct relevant performance analysis of technologies on different topics.Compared with the hardware prototype platform, the SLS software simulation platform has the advantages of low construction cost, high modification flexibility and fast verification, so it is widely used by 3GPP RAN standard organizations and various system developers.
The WiSE system hierarchical simulator simulates the overall network behavior between a large number of base stations and user equipment, which operate at the same time, interfere with each other, and influence various communication technologies, and observes the effectiveness of the overall mobile communication network including the base stations and users.
