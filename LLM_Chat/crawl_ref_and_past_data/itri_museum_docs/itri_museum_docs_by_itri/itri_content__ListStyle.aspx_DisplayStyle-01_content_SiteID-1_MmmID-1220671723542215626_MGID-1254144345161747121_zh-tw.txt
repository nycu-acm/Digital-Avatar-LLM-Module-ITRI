技術簡介
生成式 AI 智慧化應用。
2023年被視為生成式AI元年，除了文本、圖片、影片的生成外，製造研發也可導入生成式AI應用。業界目前使用生成式AI於製造研發所遇到的難題，主要來自數位IC工程師人才缺乏、工業程式設計人員能力難養成，特別是 RTL Code 的撰寫需要長期經驗的累積。
工研院發展「生成式AI智慧化應用」，專為IC設計開發 RTL Code GAI，協助工程師以提示詞（Prompt）與生成式AI互動，完成RTL模組設計撰寫。
特色與創新
易於除錯，並可在企業內建置地端服務模式，免除機敏性資料上雲安全疑慮。
應用與效益
後續將配合IC設計團隊進行場域驗證，並與長期合作的IC設計公司合作建立典範案例，促成IC設計服務生成式AI化。
