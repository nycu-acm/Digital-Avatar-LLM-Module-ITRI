Website usage guide
This website is built according to the principle of accessibility web design. The main content of the website is divided into three major blocks: 1. The upper functional block, 2. The central content block, and 3. The lower functional block.
The main block content and quick key (Accesskey) of this website are as follows:
The upper guide area (Alt+U)
: Contains [upper right menu area], [site query area], and [main menu area]. This is a common border, so any screen will appear.
In-site query area (Alt+S)
: In-site keyword query.
Central content area (Alt+C)
: It is the main content area of ​​this site. After clicking on any link, all its content will be presented in this area.This is a shared border, so any screen will appear.
Content area below (Alt+Z)
: The function block below
Operation instructions for quick keys for each browser:
Internet Explorer Please use Alt plus quick key code operation.
Firefox Please use Alt+Shift plus quick key code operation.
Google Chrome If the operating system is Windows, please use Alt plus quick key code operation.If it is Mac, use Alt+Option plus quick key code operation.
Opera Please use Shift+Esc plus quick key code operation.
Safari If the operating system is Windows, please use Alt plus quick key code operation. If the operating system is Mac, use Alt+Option plus quick key code operation.
