＃ITRI SDGS網站爬網

該爬網專門設計用於抓取ITRI可持續發展目標（SDGS）網站的https://itrisdgs.itri.org.org.tw/chi/index。

＃＃ 特徵

-  **廣度優先搜索**：通過以下鏈接系統地爬網
-  **內容提取**：從頁面中提取主要內容，同時避免導航元素
-  **智能鏈接過濾**：僅遵循同一域內的相關鏈接
-  **錯誤處理**：優雅地跳過錯誤頁面和處理異常
-  **費率限制**：包括要尊重服務器的延遲
-  **重複預防**：避免爬行兩次
-  **深度控制**：限制爬行深度以防止無限循環

＃＃ 配置

可以通過在`iTri_sdgs_crawler.py`：：

- `max_pages`：爬網的最大頁數（默認：1000）
- `max_depth`：爬行的最大深度（默認：3）
- `output_dir`：將保存爬行內容的目錄

＃＃ 輸出

爬網將在`llm_chat/itri_sdgs_docs目錄中創建文本文件。每個文件包含：

- 爬行頁面的URL
- 發現它的深度
- 時間戳被爬行
- 從頁面提取內容

##文件命名約定

文件使用URL路徑命名，例如：
- `itri_sdgs_index.txt`（用於主頁）
- `itri_sdgs_chi_about.txt`（for /chi /of）
- `itri_sdgs_chi_news_article_id123.txt`（對於新聞文章）

##內容提取策略

爬蟲使用多種策略來提取內容：

1。 **主要內容區域**：尋找語義html元素，例如<ain>`，`
2。 **截面提取**：從特定部分識別並提取內容
3。 **導航上下文**：捕獲上下文導航菜單
4。 **文本清潔**：刪除空線和格式文本以供可讀性

##鏈接發現

爬蟲發現了新頁面：

1。查找所有``<a>``href`屬性''
2。濾除非及時鏈接（PDF，MailTo，JavaScript等）
3。確保鏈接在同一域內
4。標準URL以避免重複

##錯誤處理

- 跳過404和錯誤頁面
- 優雅處理網絡超時
- 即使單個頁面失敗，繼續爬行
- 日誌調試錯誤

##費率限制

爬蟲包括尊重服務器並避免被阻止的請求之間的1秒延遲。

##監視

爬蟲提供實時反饋：
- 顯示當前頁面被爬行
- 報告的新鏈接數量
- 顯示文件保存狀態
- 顯示最終統計數據
