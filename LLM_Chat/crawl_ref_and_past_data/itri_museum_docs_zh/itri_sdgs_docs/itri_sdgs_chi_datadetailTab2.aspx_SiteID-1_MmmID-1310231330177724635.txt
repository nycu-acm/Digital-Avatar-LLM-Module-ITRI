煙道氣捕獲CO2 製造固碳材料技術
煙道氣捕獲CO2製造固碳材料技術
CO2 捕獲轉化成可再利用材料，提供CO2循環再利用解決方案。
環境(E)
社會(S)
經濟(E)
快換模組能提供患者個人專用內視鏡，減少醫療廢棄物並降低碳排放
解決醫護人力短缺的問題
促進國內醫療設備產業升級，增強國產醫材產品進軍國際市場競爭力
解決方案
建立CO2循環再利用先導設計技術，以產業界所產出的二氧化碳（CO2）作為原料，提供CO2循環再利用解決方案，協助產業解決面臨供應鏈的減碳壓力。
利用業界場域實地驗證CO2循環再利用技術，實地展示碳循環再利用技術，作為未來產業投入大型CO2循環再利用系統建置的基礎。
科技應用
+ 結合前瞻CO2捕獲技術，使CO2轉換成廠內使用的能源與資源。
+ 除了能轉換為CO2轉化聚碳酸酯等材料外，也產出甲烷、甲醇等技術、以及氣（甲烷）轉電驗證系統。
+ 透過觸媒創新與高效製程設計技術，以我國自主工程能力建立業界場
域示範系統，協助國內各產業評估並建立自主減碳技術。
成果展示
+ 有效將生產製程中所排放產生的CO2，轉化成可再利用聚碳酸酯等材料給奇美等公司使用外，藉由產出甲烷、甲醇等技術，回收廢棄材料並產換成可再利用的能源，達到節能減碳的目標。
+ 包括與仁儀場域驗證技術示範，將電子包材廠鍋爐尾氣CO2轉化為甲烷，預計一年捕抓70噸CO2，轉換甲烷26噸，發電後每年節省9萬度電。接軌國際趨勢，實踐淨零排放。
全球首創H型鋼構雷射銲接技術
全球首創H型鋼構雷射銲接技術
高能雷銲技術提升鋼構產速5倍、減碳80%，助產業低碳轉型並開拓全球鋼構市場。
環境(E)
社會(S)
經濟(E)
新製造模式可節省 80%銲料，降低 80 % 碳排，對生態環境有顯著貢獻
能在高產量兼具低耗能綠色製造效果下，達到國際淨零碳排目標
相較傳統銲接 提高 5 倍產速，降低 80% 人力，解決鋼構產業缺工問題
解決方案
本院發展兩款數位模擬技術，輔助決策H型鋼單道次雷銲參數，搭配高能雷銲低碳自動生產製造技術，為少量多樣的雷銲鋼構產品縮短70%參數確認時程，加速產業升級，革新鋼構生產作業模式，提供低碳建築可行的解決方案。
科技應用
+ 全滲透雷射銲接技術，解決人工銲接須鋼板開槽、填料及污染性熔渣廢料後處理的問題。
+ 雷射低熱影響區與機械手臂輔助雙邊同步銲接技術，解決高熱量輸入造成變形需後處理矯正的問題。
+ 雷射高能量轉換效率、機械手臂輔助與自動生產系統及免除廢熔渣後處理，提升H型鋼構產速、降低直接能耗碳排。
成果展示
+ 結合自動化設備系統，並整合高能雷射和3D列印等技術，提高鋼構產速，並降低80%人力，解決鋼構產業缺工問題。
+ 協助台灣光罩技術導入，已通過機械強度測試（SGS）、地震中心疲勞檢測及WPS（Welding Procedure Specification, 銲接程序規範）認證，並促成國內雷銲CNS標準制定與通過，截至目前已生產超過2,000公噸H型鋼構建材應用於各界。
+ 提升H型鋼構產速5倍以上，直接能耗碳排降低80%。
國際級近零低碳冷媒無油冰水機
國際級近零低碳冷媒無油冰水機，攜手產業導入市場
低碳無油冰水機，節電60%、減碳1,700kg/ 冷凍噸，助力產業淨零轉型與國際市場拓展。
環境(E)
社會(S)
經濟(E)
採環境友善低碳冷媒之冰水機，每冷凍噸減碳可負擔的潔淨能源工業化、創新及基礎建設
加速高能耗高碳排冰水機的汰換速度，帶動能源效率之使用最大化1,700 kg提升節電效能達20 %以上
促成產業具備自主生產低碳無油冰水機與壓縮機量能，推廣導入市場應用，助力企業淨零永續發展
解決方案
本院開發出國際最高能效之低碳冷媒（GWP1）
（註）
冰水機與關鍵壓縮機模組，具備無油、無摩擦、低污染、低噪音、低耗電、廣域運轉與遠端即時監測等優勢，為友善工作環境、永續消費及生產、深度節能提供科學化驗證，並建立下一世代冰水機之最佳解決方案。
科技應用
+ 開發自主關鍵零組件與技術，包含專利噴淋式熱交換裝置、無油壓縮機、組件設計等，突破國際禁用高GWP冷媒與導入低碳冷媒能效衰退瓶頸，促使壓縮機效能超越國際標竿，推升冰水機節電與減碳效益，助攻企業實現淨零。
成果展示
+ 聯手壓縮機龍頭廠復盛及漢鐘（全球螺旋式壓縮機市佔>40%），共同開發低碳無油壓縮機，推動商品化。
+ 正式導入半導體業-環球晶圓廠區的冰水機汰舊換新實場應用，相較於原高碳排冷媒冰水機，運轉節電量達60%。
+ 攜手國內企業合作，建構上下游國產自主供應鏈。
