# 爭議

2025年4月，工業技術研究院（工研院）於執行衛生福利部「次世代數位醫療平臺（頁面存檔備份，存於網際網路檔案館）」計畫期間，因未依規定標註開源專案授權內容，且於另一國家標準專案「TW Core IG」的授權條款中明文禁止特定個人與公司使用該專案，引發開源社群廣泛關注與爭議。[3]2025年4月16日，一名工程師（下稱「當事工程師」）於 GitHub 專案ITRI-BDL-D/CQL-Project-template（頁面存檔備份，存於網際網路檔案館） 中新增 issue 討論[4]，指控工研院未遵守Apache-2.0 授權條款（頁面存檔備份，存於網際網路檔案館），將美國 AHRQ 開源專案CQL-Testing-Framework（頁面存檔備份，存於網際網路檔案館） 程式碼複製後上傳至其管理的專案中，卻未附上原始授權聲明[5][6]。同日，工研院補上授權檔案，但仍未標註原作者等必要資訊，不符合授權條款要求[7]。2025年4月19日，工研院於TW Core IG專案中更新授權條款，明文禁止當事工程師及其公司使用該專案內容，引發外界質疑政府資源不應針對特定個人設限[8]。2025年4月19日，工研院更新授權條款，解除上述限制，聲明「我們已知當事工程師經過此次事件已了解其於其專案之 CC BY-NC-SA 4.0 許可證特別禁止工研院使用也是一件不好的事，故我們針對我們的專案的許可證取消對其限制。」[9]。2025年4月19日，當事工程師回應，指出其專案設定限制條款的原因，是因工研院「在未經同意、未經知會的狀況下，擅自將其專案納入醫資大平台，作為 KPI？」，並呼籲工研院應公開道歉[10]。2025年4月19日，衛福部資訊處發表聲明，感謝民眾對開源授權標示的提醒，該程式原本就可以從美國的網站公開取得 ，為了避免不需要的誤解，本部已經要求提供工具原網站連結為主；醫療資訊大平台所提供的各項數位工具與資源，在合理、正當的使用前提下，本部絕對不會設限或阻擋大家的應用[11][12]。2025年4月20日，工研院對授權標示不全公開致歉，表示將於一週內完成技術架構與文件指引的全面檢視，並強調未來將強化與開源社群合作，落實知識共享精神。然而，針對限制特定人士使用政府公共資源部分，則未提出具體說明[13][14]。
2025年4月16日，一名工程師（下稱「當事工程師」）於 GitHub 專案ITRI-BDL-D/CQL-Project-template（頁面存檔備份，存於網際網路檔案館） 中新增 issue 討論[4]，指控工研院未遵守Apache-2.0 授權條款（頁面存檔備份，存於網際網路檔案館），將美國 AHRQ 開源專案CQL-Testing-Framework（頁面存檔備份，存於網際網路檔案館） 程式碼複製後上傳至其管理的專案中，卻未附上原始授權聲明[5][6]。同日，工研院補上授權檔案，但仍未標註原作者等必要資訊，不符合授權條款要求[7]。2025年4月19日，工研院於TW Core IG專案中更新授權條款，明文禁止當事工程師及其公司使用該專案內容，引發外界質疑政府資源不應針對特定個人設限[8]。2025年4月19日，工研院更新授權條款，解除上述限制，聲明「我們已知當事工程師經過此次事件已了解其於其專案之 CC BY-NC-SA 4.0 許可證特別禁止工研院使用也是一件不好的事，故我們針對我們的專案的許可證取消對其限制。」[9]。2025年4月19日，當事工程師回應，指出其專案設定限制條款的原因，是因工研院「在未經同意、未經知會的狀況下，擅自將其專案納入醫資大平台，作為 KPI？」，並呼籲工研院應公開道歉[10]。2025年4月19日，衛福部資訊處發表聲明，感謝民眾對開源授權標示的提醒，該程式原本就可以從美國的網站公開取得 ，為了避免不需要的誤解，本部已經要求提供工具原網站連結為主；醫療資訊大平台所提供的各項數位工具與資源，在合理、正當的使用前提下，本部絕對不會設限或阻擋大家的應用[11][12]。2025年4月20日，工研院對授權標示不全公開致歉，表示將於一週內完成技術架構與文件指引的全面檢視，並強調未來將強化與開源社群合作，落實知識共享精神。然而，針對限制特定人士使用政府公共資源部分，則未提出具體說明[13][14]。
