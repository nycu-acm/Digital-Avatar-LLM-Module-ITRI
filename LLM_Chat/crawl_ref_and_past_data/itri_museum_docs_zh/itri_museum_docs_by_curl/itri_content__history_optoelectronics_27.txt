3D列印
2000年起3D列印（積層製造）技術成長飛快，開始應用於模具製造、生技醫材、航太領域。為協助產業高值化，工研院發展3D列印技術，2012年籌組「雷射積層製造產業群聚」，引進國內第一台雷射3D列印設備，並建置國內第一個金屬雷射積層製造實驗室，結合國內外設備、材料、應用等30餘家廠商，推動金屬3D列印發展關鍵技術，應用於客製化醫材，包括牙齒、人工支架、人工骨、人工關節及手術器械，為智慧醫療提供助力。
2013年開始投入技術研發，先後完成AM100、AM250與國內最大型的500X500X500立方公分的設備開發，並於2014年以自行設計製造的蘭花金簪參加新加坡國際3D列印競賽獲得首獎，打開臺灣在3D列印領域的知名度。同年為拓展國際能量，與投入3D列印研究超過15年經驗的荷蘭TNO合作，共組「3D列印國際聯盟」，2015年成立「3D列印國際研發平台」，推出國內第一台以工業用機器手臂設計的大型化FDM 3D列印機，可列印大尺寸工件，透過平台攜手臺歐3D列印廠商，加速技術研發，共同進軍3D列印國際市場。
航太領域方面，2017年開發國內第一台大面積雷射金屬積層製造設備，因應金屬積層製造產品大型化與多樣量產之需求，協助臺灣廠商力拚航太商機。與漢翔公司、晉陞公司合作投入航空太空零組件之雷射金屬積層製造，及其相關特色產品研發與製作模擬評估，協助廠商突破傳統加工極限，朝高性能的航太零組件研發邁進。
在生醫領域方面，推動生醫3D列印噴印技術，協助國內生醫產業建立特殊客製化生醫材料快速製造生產設備，瞄準高附加價值醫材領域，2018年於南部科學園區高雄園區建置「3D列印醫材智慧製造示範場域」，提供從設計、試製到商品化製作的一站式服務，滿足醫院、醫材公司等各種客製化產品試製需求，促成南臺灣成為金屬醫療器材產業群聚之重鎮。2019年與高雄榮總、全球安聯公司合作建置國內首創3D列印醫材體驗診線，選定頭頸部口腔癌患者的下顎彌補物為示範，協助南部科學園區醫材及周邊金屬產業，跨入新興3D列印供應鏈，開啟精準醫療商機。
2012
完成國內第一個金屬雷射積層實驗室。
2012
籌組「雷射積層製造產業群聚」，結合國內外設備、材料、應用等產學研30餘家廠商，宣誓跨進3D列印產業。
2013
與荷蘭TNO簽訂「積層製造國際聯盟」合作，開發高科技、高精度、高複雜度零件及產品為合作目標。
2014
與荷蘭TNO合作建立「3D列印國際研發平台」，鏈結臺歐3D列印廠商投入國際市場。
2014
工研院獲2014新加坡國際3D列印競賽首獎的蘭花金簪作品。
2015
發表第一台國人自製雷射金屬3D列印設備及材料，協助國內廠商切入金屬3D列印商機。
2016
結合國內20家3D列印業者成立「3D列印應用產業聯盟」，投入醫材、文創、車輛及航太模具等最新跨域應用，讓產品一體成形快速製造。
2017
開發國內第一台大面積雷射金屬積層製造設備，解決金屬積層製造產品大型化與多樣量產之需求，助臺廠拚航太商機。
2018
南科高雄園區建置全國首座一站式「3D列印醫材智慧製造示範場域」，提供國內廠商專機專用的3D列印植入醫材設計、製造與認證一站到底代工服務。
2018
攜手臺大醫院、法德利科技與可成生技，成立國內第一個「個人客製化醫材」平台與產業鏈。
2018
攜手新竹馬偕研發3D列印輔護具，以「3D列印設計服務共創平台」開發完成腕隧道症候群〈滑鼠手〉、媽媽手、踝足矯形器及幼兒上臂義肢等客製化3D列印輔護具。
2018
發表客製化醫材-口顎彌補物。
2018
研發大型航太3D列印零件。
2019
與高雄榮總及全球安聯合作建置臺灣首創「3D列印醫材體驗診線」，以創新科技打造個人化的智慧醫療體驗。
2020
研發「智慧化積層不NG製造技術」，可一次到位、精準製作3D列印零組件，應用於精密製作的航太產業。
2021
首創「促進組織整合仿生3D列印技術」，打造出「仿生中空骨釘」，技轉可成生技，協助取得醫材上市許可，榮獲全球百大科技研發獎。
